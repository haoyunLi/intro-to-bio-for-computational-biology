先猜：TSPAN6 的 unstranded = 3928 最准确地表示什么？

为什么：原始 unstranded 是 gene-level count。一个组织含许多细胞；RNA 提取、建库、测序和 read 分配会共同影响这个数字。tpm_unstranded = 59.4987 是另一个尺度，不能与 3928 当同一单位比较。

文件摘录来自 GDC 官方完整 TSV；计数与变换定义见 GDC mRNA 管线。

要理解为何同一行还有 TPM / FPKM：动手切换 raw count、CPM 与 TPM ↗，再读 Q05–Q07 的分母与用途。这一份文件没有生物重复，不能在这里做差异表达检验。

04 · ZERO IS A MEASUREMENT RESULT

WNT16 = 0：是“没有这个基因”吗？

这份真实文件中，ENSG00000002745.13 / WNT16 的 unstranded = 0 且 tpm_unstranded = 0.0000。它和 N_unmapped 行的空白字段也不一样：WNT16 是注释中的基因行，数值确实写为 0。

真实基因行WNT16unstranded 0
非基因汇总行N_unmappedgene_name 空白

先猜：读到 WNT16 的 0，现阶段能写出的结论是什么？

为什么：0 是这次量化的输出；它不证明基因从基因组中消失，也不证明每个细胞绝对没有该 RNA。测序深度、组织组成、注释与多重映射都可能影响低值或零值。GDC 文档也特别说明，某些被其他基因完全包围的基因可因计数规则而显示零。

真实零值：本站精确摘录；计数歧义说明：GDC mRNA 管线，Expression Workflow。

05 · THE BOUNDARY OF ONE FILE

38670 不是“ERBB2 导致癌症”。

同一文件中 ERBB2 的 unstranded = 38670、tpm_unstranded = 257.4313。这些是这份材料经指定流程得到的 RNA 层数值。没有第二组独立病例、对照与设计，就没有“组间差异”；没有蛋白、临床或干预证据，也不能宣布 HER2 状态、治疗效果或致病机制。

先猜：只凭这个文件，哪一句可以成立？

为什么：差异表达至少需要明确比较组与独立生物重复；临床因果和治疗预测需要另外的设计与证据。现在唯一稳妥的结果是一个带来源、单位和限制的文件级观察。
