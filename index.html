00THE BIG PICTURE

生命是一个有层级的系统

不要一上来背通路名。先把研究对象看清楚：一个人的肿瘤由组织组成，组织里有多种细胞；细胞内有分子，分子之间的相互作用会改变细胞行为。[3]

分子MoleculeDNA / RNA / Protein
→

→

→

CS 类比 / A useful analogy

基因组像一份长期保存的指令集合；RNA 更像当前运行状态的读数；蛋白质参与执行功能。这个类比只帮助定位层级，不等于“一个基因决定一个结果”。[2] [4]

研究问题 / A better question

“这个基因在癌症中重要吗？”太宽。更可操作的是：“在同一癌种、同一种样本定义下，它的表达是否与某种表型相关？这个信号可能来自哪类细胞？”

01CELL & GENETICS

先认识细胞，再谈基因

细胞 cell 是生命的基本单位。人体组织不是同一种细胞的复制品；肿瘤样本也混有肿瘤细胞、免疫细胞和基质细胞。因此，bulk 测量常是多种细胞信号的混合。[3] [5]

01

Cell ≠ sample

一个测序样本可以来自一块组织；一块组织可以含有很多种细胞。分析单位先于算法。

02

Nucleus / 细胞核

在人类细胞中，主要的核基因组装在染色体里；线粒体也有少量 DNA。[6]

03

Phenotype / 表型

可观察的特征来自遗传、环境和细胞状态共同作用。[4]

WHY CANCER IS A SYSTEMS PROBLEM

为什么肿瘤需要多组学？

癌症涉及细胞生长和分裂调控失常；同一个肿瘤内的细胞也可能携带不同改变。它还与免疫细胞、基质和血管构成的 tumor microenvironment / 肿瘤微环境 相互影响。DNA、RNA、蛋白和影像分别看到这个过程的一部分。[28] [29]

02GENETIC BASICS

DNA、gene、variant 到底是什么？

DNA 是储存遗传信息的分子；chromosome / 染色体 是 DNA 与蛋白质组成的结构；genome / 基因组 指一个细胞里的整套 DNA 信息；gene / 基因 是其中具有功能信息的区域。它们是不同层级，不能互换。[1] [8] [6] [9]

SEQUENCE

变异 / Variant

DNA 序列与参考序列的差异。Somatic mutation 在体细胞中获得；germline variant 可从父母遗传。肿瘤研究常关心体细胞改变。[10]

AMOUNT

拷贝数 / CNV

某段 DNA 的份数增加或减少。它可能影响表达，但不能单凭 CNV 推断蛋白质功能。[7]

CONTEXT

调控 / Regulation

相同 DNA 在不同细胞里可以被不同方式使用；表观遗传标记与调控元件参与这个过程。[11] [12]

读论文时先问：作者说的“mutation”是肿瘤体细胞突变、胚系变异，还是只是表达量变化？这三者不能当同一个变量。
03INFORMATION FLOW

DNA → RNA → Protein → phenotype

Central dogma 提供最简信息流：DNA 经 transcription / 转录 产生 RNA，RNA 经 translation / 翻译 参与蛋白质合成。真实系统还有剪接、调控、降解、蛋白修饰和环境反馈，所以各层数据不会一一对应。[2] [5] [11]

想一步一步看懂？ 教材第 M02–M05 章分别讲信息流、转录、RNA 加工和翻译。从 Central Dogma 开始 ↗

DNA 看“可能性”
变异或拷贝数提示机制候选，不能直接读出活性。

RNA 看“测得的丰度”
RNA-seq 提供采样时 RNA 的计数或相对丰度，不直接测转录速率，也不等于蛋白量。[5]

蛋白看“功能机器”
丰度、修饰与位置都可能重要；一种测量往往只覆盖其中一部分。[17]

05RESOLUTION

同一块肿瘤，三种观察方式

Bulk RNA-seq 把一块组织里的 RNA 合在一起读；single-cell RNA-seq 把读数分配给单个细胞，帮助辨认细胞类型和状态；spatial transcriptomics 再把信号放回组织坐标。三者回答的问题不同，分辨率也各有代价。[5] [25] [26]

Bulk 一块组织 → 一个读数

适合研究群体差异，但基因表达改变可能来自细胞比例变化，也可能来自细胞内状态变化。

gene × tissue sample

Single-cell 一个细胞 → 一个读数

可以发现少数细胞群和细胞状态；组织位置通常在解离时丢失，且需要质量控制和注释。

cell × gene + metadata

Spatial 表达 + 位置

把分子信号与组织结构联系起来；测量单位可能是 spot、区域或单细胞，须看平台说明。

location × gene + x/y
统计单位提醒：一位病人的上万个细胞并不等于上万个独立病人。若结论要推广到病人群体，要考虑生物学重复、病人层级和相应的统计设计。[27]
06BIOIMAGE

图像也是一种生物数据

显微镜图像看细胞与亚细胞结构；病理全切片 whole-slide image, WSI 看组织形态；CT/MRI 看更大尺度的解剖结构。它们的标签、分辨率与分析单位不同，不能统称为“图片分类”。[19] [20]

Microscopy

像素 → 细胞分割 → 形态、位置、共定位

常见资源：IDR[19]

Pathology / WSI

整张切片 → tiles → 组织区域 → 病例级汇总

TCGA/GDC 可包含数字病理切片[7]

CT / MRI

体素 → 器官或肿瘤区域 → 影像特征

常见资源：TCIA[20]
做 ML 时的关键：如果同一位病人的多个 tile 或切片落在 train 和 test 两边，评估会泄漏病人特征。按 patient/case 切分，并检查扫描仪、染色或中心是否成为 shortcut。

08TCGA CASE STUDY

把一个 TCGA 问题走完整

示例问题：在一个指定癌种中，某基因的表达与临床结局是否相关？先把“可分析的 cohort”定义清楚，再写模型。TCGA 是研究项目，GDC 提供访问与协调处理后的数据。[14] [7]

  1. 01

    Define question

    指定癌种、样本类型、暴露变量、结局和预期混杂因素。不要从一个显著 p 值倒推问题。

  2. 02

    Define units

    区分 case / 病例、sample / 样本、aliquot / 分装物、file / 文件。多个文件不代表多个独立病人。[23]

  3. 03

    Build cohort

    在 GDC 选项目、primary tumor 或 matched normal、assay 和可用临床字段；记录纳排标准和缺失情况。[7]

  4. 04

    Join modalities

    按明确的 ID 层级对齐 RNA、变异、甲基化与临床资料；不同组学的样本交集可能变小。检查参考基因组与处理版本。[24]

  5. 05

    Analyze and challenge

    检查批次、组织来源、肿瘤纯度、缺失和多重检验；对结局模型核对随访与删失定义。寻找独立队列或实验支持。

先看一个可核对的输入：逐行读一份公开 TCGA-BRCA STAR counts 文件 ↗。再用 四份真实文件拼出两位病例的配对小队列 ↗，练习筛选、连接、读数单位与推断边界。这是经过选择的教学子集，不代表可做组间统计的完整队列。

研究结论的边界

“表达与生存相关”只是 association，不证明该基因驱动疾病，也不等于临床可用 biomarker。GDC 也将其数据定位为研究探索。[7]
