# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Computational researchers learning biology and statistical analysis. The user requests Chinese intuitive explanations with English technical names and stepwise numerical reasoning. Their selected priority is Spatial bin-to-cell, EM/RL and assignment uncertainty; related paths include Pathway/Age and Methylation/Age.

## Product Purpose

Connect biological mechanisms to assay signals, matrix units, analysis choices and evidence limits. Extend the existing biology foundation with topics in the supplied CB_592 lectures and R demos, then connect Bulk RNA-seq and functional analysis to single-cell and spatial workflows.

## Capabilities and Constraints

Static HTML/CSS/JavaScript published through the existing GitHub Pages repository. Preserve existing chapters, routes and browser-local progress. New teaching modules should expose input, output, intermediate arithmetic, parameters, when to use, strengths, limitations and troubleshooting. Course topic coverage is original teaching, not a hosted copy of private lecture PDFs, assignments or datasets.

## Brand Commitments

Bio/CS is the established site. Preserve its editorial reading hierarchy and visual identity. Technical terms remain English; explanatory prose is primarily Chinese. The user requests explanatory figures and purposeful interaction following the research-talk-slides teaching approach.

## Evidence on Hand

Existing textbook, Foundations Lab, Data Lab, Project Lab, mechanism workbench and primary-source links. User supplied CB_592 lecture PDFs, R Markdown demos, Quarto assignments, a Bulk RNA-seq guide and Bulk/functional-analysis demo sources. Spatial workflow coverage is an explicit extension beyond the supplied lecture material.

## Product Principles

- Begin with a biological question and the unit being observed.
- Show the numerical consequence of changing one assumption or setting.
- Separate measurement, model output and supported biological inference.
- Preserve donor/sample structure and distinguish synthetic examples from empirical results.
- Provide source-to-topic coverage and runnable, documented examples.
