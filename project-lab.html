      目标不是生成“正确分析方案”，而是让你在运行任何模型前，能解释研究对象 → assay signal → 数值 → 分析 → 有限结论。

      先看一份完整示范：为什么不能把 18% VAF 写成 18% 癌细胞？
      生物问题
      Progression specimen 新出现的 NRAS signal，是否可能参与 MAPK rebound？
      对象与设计
      同一患者的 T1 与 T3 来自不同时间、不同病灶；它们是两个 specimens，却不是两个独立患者。
      直接测量
      DNA-seq 经过 alignment 和 filtering 后，T3 的 100 条 reads 中有 18 条支持 NRAS ALT。
      数值与方法
      VAF = 18 / 100。先核对 matched normal、coverage、mapping 与 caller，再结合 purity 和 copy number 讨论 clone；不能用 VAF 直接替代 cell fraction。
      有限结论
      NRAS 是与 progression 同时出现的 resistance candidate；单一患者、不同病灶和未做 perturbation，不能证明它导致耐药。
      下一步
      独立验证 variant，并在相关模型中 perturb NRAS，观察 pERK 和生长是否改变，再尝试 rescue。

      先选你手里的数据

      这些是练习解释数据与方法的场景，不等于为真实数据自动推荐统计方案。

      1. 固定生物问题与观察对象

      写成能被数据检验的一句话，避免“找所有有趣的 gene”。

      分开写 patient、specimen、取样时间/位置、cell 和 biological replicate。

      2. 从 assay 走到文件里的一个数

      先说 assay 和原始观察；不要直接把处理后的列名当作生物事实。

      写出一行/一列分别代表什么，及 normalization、caller 或 segmentation 做了什么。

      3. 为什么这种分析与设计相配？

      方法名之外，说明它接受什么输入、要估计什么，以及关键假设。

      想想 batch、purity、cell composition、missingness、重复测量和数据泄漏。

      4. 把结论停在证据允许的位置

      标明 observation、association、prediction 或 mechanism；写出样本与数据范围。

      一个明确的 alternative explanation，比列十个模糊 caveat 更有用。

      COMPUTATIONAL-BACKGROUND TRAPS

      九个需要形成条件反射的“不等于”。

      • gene ≠ transcript
      • RNA ≠ protein activity
      • read ≠ molecule
      • zero ≠ absence
      • cluster ≠ cell type
      • cell ≠ independent patient
      • accessibility ≠ enhancer function
      • metabolite abundance ≠ flux
      • prediction ≠ mechanism
