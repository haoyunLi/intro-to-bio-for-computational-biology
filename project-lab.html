      COMPUTATIONAL-BACKGROUND TRAPS

      九个需要形成条件反射的“不等于”。

      • gene ≠ transcript
      • RNA ≠ protein activity
      • read ≠ molecule
      • zero ≠ absence
      • cluster ≠ cell type
      • cell ≠ independent patient
      • accessibility ≠ enhancer function
      • metabolite abundance ≠ flux
      • prediction ≠ mechanism
