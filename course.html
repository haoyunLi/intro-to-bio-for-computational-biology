LESSON 01 / 12GENETICS · START HERE

Genetics 在研究什么？

先弄清研究对象与问题，后面的术语才有位置。

  • 区分 genetics、genomics 与 gene expression
  • 说清 genotype 和 phenotype 的关系
  • 区分遗传差异、肿瘤突变与表达变化
01 · FIRST IDEA

Genetics 的核心问题是“差异如何传递、如何产生影响”

Genetics / 遗传学研究遗传和 DNA 差异；genomics / 基因组学把研究范围扩展到整套基因组及其相互作用。一个计算研究常从三种问题进入：序列有什么差异？这些差异如何影响分子或细胞？最后与什么可观察特征相关？

这里的 genotype / 基因型 是某个位置上实际携带的 DNA 版本；phenotype / 表型 是可观察特征，例如一种疾病状态。中间隔着调控、细胞类型、时间和环境，所以从 genotype 到 phenotype 不是单行代码直接返回结果。[NHGRI]

DNA variation序列差异
→
Molecular process表达与调控
→
Cell behavior细胞行为
→
Phenotype可观察结果

原创教学图 · 概念依据 NHGRI Genetics、NHGRI Phenotype。

02 · KEEP THREE THINGS APART

研究中最容易混淆的三类“变化”

问题变量是什么肿瘤例子
Inherited variant
胚系变异		可从父母传给子女的 DNA 版本研究遗传易感性
Somatic mutation
体细胞突变		身体某个细胞及其后代中获得的 DNA 改变比较肿瘤与同一人的正常样本
Expression change
表达变化		RNA 或蛋白丰度的变化某基因在肿瘤组织中的 RNA 丰度更高

前两行都是 DNA 层面的概念，第三行是分子活动的读数。表达量变化可能受突变影响，也可能来自不同细胞比例、外部刺激或调控变化。[NHGRI Mutation] [NHGRI RNA-seq]

03 · A QUESTION YOU CAN TEST

把一个大问题拆成四个可测的问题

假设某个肿瘤样本中发现一个 DNA 变化。研究者会先问：① 变化真的存在吗？ 用测序读段与质量信息验证；② 它位于哪里？ 对照参考基因组与基因注释；③ 有什么分子后果？ 检查 RNA、蛋白或调控数据；④ 与细胞行为或患者结局有关吗？ 在合适队列中比较并寻找独立证据。后面的课程依次提供回答这些问题所需的语言和数据观念。

这四步也说明为什么不能跳过基础术语：一个“基因变了”的说法，可能指序列、拷贝数、表达或细胞比例，四者对应不同实验与统计单位。

给 CS 读者的翻译

DNA sequence 比较接近长期保存的状态；一次 RNA 测量更接近特定时间、特定细胞集合里的运行快照。这是帮助定位数据层的类比，不能把细胞当成确定性程序。

检查理解：某基因 RNA 值变高，能否说它发生了突变？

不能。RNA 值说明在该样本和测量条件下观察到的表达水平；突变需要 DNA 层面的证据。接下来我们先学习 DNA 本身。

本课来源 NHGRI Genetics · Genotype · Phenotype · Mutation

LESSON 02 / 12GENETICS · MOLECULAR ALPHABET

DNA 的四个字母

先把 DNA 当作有方向、有配对规则的物理分子。

  • 说出 A、T、C、G 与碱基配对
  • 区分碱基、核苷酸和 DNA 链
  • 读懂一段双链序列的方向
01 · BUILDING BLOCKS

DNA 是由 nucleotide 串成的长分子

Nucleotide / 核苷酸包含糖、磷酸与一个碱基。DNA 常用四种碱基缩写：A（adenine）、T（thymine）、C（cytosine）、G（guanine）。它们在长链上的排列顺序就是 sequence / 序列；字母是信息的表示，真实对象是化学分子。[NHGRI]

DNA 通常由两条方向相反的链组成：A 与 T 配对，C 与 G 配对。若一条链写作 5′–A C G T–3′，与它配对的链应写作 3′–T G C A–5′。5′ 与 3′ 是链的化学方向；比较序列时，方向搞错会得到完全不同的解释。

02 · WHY THIS MATTERS

复制、测序和比对都离不开这些规则

细胞分裂前会复制 DNA，让子细胞获得遗传信息。研究者测序时通常得到很多短片段的 reads / 读段，再把它们放到参考基因组上，推断样本的序列。在 DNA 测序场景中，FASTQ、BAM 和 VCF 分别对应读段、比对与变异记录；常见短读长 RNA-seq 的 FASTQ/BAM 则来自 RNA 经逆转录成 cDNA 后的测序。解释文件前先看 assay。[GA4GH formats] [GDC RNA workflow]

重要边界：序列本身不会告诉你一个基因在某种细胞中是否正在被使用；那需要表达或调控层的测量。

03 · MAKE A COPY

为什么配对规则让复制成为可能？

细胞分裂前会进行 DNA replication / DNA 复制。两条链分开后，每条旧链都可作为模板：遇到 A 配 T，遇到 C 配 G，逐步合成互补链。真实复制由蛋白质机器完成，并有校对与修复过程；“字母配对”只是理解机制的第一层。若复制或修复后保留下序列差异，它可能成为后代细胞携带的变异。[NHGRI DNA Replication]

小练习：给定 5′–A T C–3′，先写互补链 3′–T A G–5′，再反向写为 5′–G A T–3′。基因组工具里常见的 reverse complement就是“互补 + 反向”两步。

给 CS 读者的翻译

序列是一个方便计算的字符串视图，但“字符串相同”不等于“生物状态相同”。不同细胞可以共享近似相同的 DNA，却具有不同的 RNA、蛋白与功能。

检查理解：5′–A C G–3′ 的配对链按相反方向怎么写？

3′–T G C–5′。如果想把配对链也按 5′→3′ 写，需要反向排列成 5′–C G T–3′，即 reverse complement。

本课来源 NHGRI Nucleotide · DNA · DNA Replication · GA4GH HTS formats

LESSON 03 / 12GENETICS · THE MAP

基因组的地址系统

染色体、基因、位点与等位基因是不同层级。

  • 解释 genome、chromosome、gene、locus
  • 说明 allele 为什么是“某个位点的版本”
  • 理解为什么坐标必须带参考基因组版本
01 · ZOOM IN

从一整套 DNA，逐层放大到一个位置

Genome / 基因组 是整套 DNA 信息；在人类细胞中，主要核基因组排列在 chromosomes / 染色体上。多数人体细胞有 23 对染色体；这是典型情况，肿瘤细胞可能有染色体数目或结构异常。[NHGRI]

Gene / 基因 是具有功能信息的 DNA 区域，不是整条染色体。Locus / 位点是基因组中的具体位置；allele / 等位基因是该位置的某个 DNA 版本。一个位点可以有多个可能版本，但一个个体在典型二倍体常染色体位点上通常有两份。[NHGRI Allele]

02 · DATA ADDRESS

一个坐标需要“地图版本”

数据库会用染色体和位置表示位点，例如教学用虚构写法 chr1:1000。但只有坐标还不够：必须知道参考基因组版本（如 GRCh38），否则同一个数字可能指向不同的序列位置。Reference genome / 参考基因组 是比较标准，不是一位“标准人”的完整 DNA。[NHGRI]

做数据连接时，同时记录 genome build、基因注释版本和 ID 类型。仅凭一个 gene symbol 或一个裸坐标合并表格，很容易把不同对象错误地连在一起。

03 · GENE IS NOT ONE BLOCK

基因边界与蛋白编码区也不相同

很多人类蛋白编码基因包含 exon / 外显子与 intron / 内含子。转录后，内含子通常被剪掉，部分外显子连接形成成熟 RNA；并不是每个外显子都编码蛋白。还有只产生功能性 RNA 的基因。WES / whole-exome sequencing主要针对外显子相关区域，不能当作完整的全基因组测序。[NHGRI Exome]

所以“一个基因”在数据库里可能对应基因层、转录本层或蛋白层多个 ID。读表前先看第一列到底是哪一层，以及使用了哪版注释。

给 CS 读者的翻译

把 chr1:1000 想成文件偏移量：不写“文件版本”就无法确保它仍指向同一段内容。参考基因组 build 就是坐标系统的一部分。

检查理解：gene、locus、allele 分别回答什么问题？

Gene：这段 DNA 有什么功能信息；locus：它在基因组哪里；allele：这个位置具体是哪一个序列版本。三者不能互换。

本课来源 NHGRI Genome · Chromosome · Gene · Locus · Allele · Exome

LESSON 04 / 12GENETICS · INHERITANCE

遗传如何发生？

“两份染色体”是理解 genotype 和遗传的起点。

  • 区分 diploid 与 haploid
  • 读懂一个简单 Punnett square
  • 知道显性/隐性不是所有性状的通用规律
01 · TWO COPIES

父母各给一套，大多数体细胞保留两套

人类大多数体细胞为 diploid / 二倍体，通常有两套染色体，分别来自父母。卵子与精子是 haploid / 单倍体；形成它们的 meiosis / 减数分裂会让染色体套数减半。受精后两套重新结合。[NHGRI]

在一个典型二倍体常染色体位点，个体携带来自两条同源染色体的两个 allele。它们相同可称 homozygous / 纯合，不同称 heterozygous / 杂合。描述这两份版本的组合，就是该位点的 genotype / 基因型，例如 Aa。[NHGRI Allele]

02 · A SIMPLE MODEL

用 Aa × Aa 练习概率，而不是预测所有现实性状

假设一个位点有 A 与 a 两个 allele；两个亲本的基因型均为 Aa。每个亲本在此简化模型下各有一半机会传 A 或 a。四种组合如下：

×Aa
AAAAa
aAaaa

因此基因型比例为 1 AA : 2 Aa : 1 aa。只有在单个位点、完全显性且其他因素不改变表现时，才可把它进一步简化为 3:1 的表型比例。[NHGRI Dominant]

03 · REALITY CHECK

遗传概率 ≠ 个体命运

显性和隐性描述特定 allele 与性状在特定模型下的关系。很多人类特征和疾病受多个位点、环境以及细胞状态共同影响；同一 genotype 也不保证相同 phenotype。肿瘤中的许多体细胞突变发生在个体生命过程中，通常不会像胚系变异那样传给子女。[NHGRI Phenotype] [NHGRI Mutation]

04 · RECOMBINATION

子代并非直接复制父母的整条染色体

减数分裂时，成对的同源染色体可发生 crossing over / 交换，把来自父母的 DNA 片段重新组合。因此同一条染色体上的两个位点不一定永远一起传递；距离较近的位点通常更可能共同遗传，这叫 linkage / 连锁。后面读 GWAS 或群体遗传结果时，这个概念很重要。[NHGRI Crossing Over]

给 CS 读者的翻译

Punnett square 是一个很小的概率模型，显式写出了前提。遇到真实数据时，先问这些前提是否满足，而不是把 3:1 当成普适规律。

检查理解：Aa × Aa 时子代为 aa 的概率是多少？

在这个简化模型下为 1/4。这个数针对基因型；是否出现某种表型还取决于该性状的遗传机制。

本课来源 NHGRI Diploid · Meiosis · Allele · Dominant · Crossing Over

LESSON 05 / 12GENETICS · VARIATION

变异与突变：读懂 DNA 的差别

先定义比较对象，再解释一个“突变”。

  • 区分 SNV、indel、CNV
  • 区分 germline 与 somatic
  • 读懂最简 VCF 中的位置与等位基因
01 · WHAT CHANGED?

Variant 是与参考序列比较的差异

参考序列某个位点是 A，而样本是 G，这是一个 single-nucleotide variant, SNV / 单核苷酸变异。一个或多个碱基被插入或删除是 indel；一段 DNA 的份数增加或减少是 copy-number variation, CNV / 拷贝数变异。更大范围的重排可改变染色体结构。变化的尺度不同，检测方法、数据形状和解释也不同。[NHGRI Mutation]

SNVA C G T一个碱基改变
INDELA C T T G插入或删除
CNV[A B] [A B] [A B]片段份数变化

这里的字母只是示意。有变异不自动意味着有害或驱动肿瘤；还需考虑位置、频率、功能证据和测序质量。[NCI]

02 · WHEN DID IT ARISE?

胚系与体细胞，是两种来源

Germline variant / 胚系变异来自生殖细胞谱系，通常可在身体许多细胞中检测到，并可能传给下一代。Somatic mutation / 体细胞突变在生命过程中某个细胞及其后代中出现；肿瘤研究常关心它。比较同一人的肿瘤与正常样本有助于识别体细胞改变，但取样、肿瘤纯度和测序误差都会影响判读。[NCI Cancer Genetics]

03 · READ A RECORD

VCF：把差异写成带坐标的记录

VCF / Variant Call Format 的核心字段包括染色体 CHROM、位置 POS、参考等位基因 REF 和替代等位基因 ALT。下面是虚构教学例子：

TOY EXAMPLE · 假设的 chr1 坐标与 REF（不是实际 GRCh38 记录）
#CHROM  POS   REF  ALT
chr1    1000  A    G

这份四字段教学摘录表示：假设该参考位置为 A，替代等位基因为 G；它不是真实基因组核对后的记录，也不是完整 VCF。仅凭四列不能断定样本基因型、质量、体细胞身份或功能。完整 VCF 还需要 ID、QUAL、FILTER、INFO 列，可能另有样本字段。[GA4GH VCF]

给 CS 读者的翻译

Variant 像带版本号的 diff。缺少参考 build、比对方式或质量信息时，这个 diff 不宜直接合并或解释。

检查理解：肿瘤样本中发现 G，为什么还不能叫它“肿瘤驱动突变”？

要先确定位置、测序质量及它是否真是体细胞改变；即便成立，仍需功能或统计证据支持“驱动”。

本课来源 NHGRI Mutation · CNV · NCI Cancer Genetics · GA4GH VCF specification

LESSON 06 / 12MOLECULAR BIOLOGY · CENTRAL DOGMA

Central Dogma：从 DNA 到蛋白质

沿着一段真实的“信息路线”走六步，再看它在哪些地方会分叉。

  • 区分 DNA 复制、转录与翻译
  • 从 coding/template DNA 写出 mRNA
  • 按 reading frame 读出 codon 和氨基酸
  • 解释剪接、非编码 RNA 与逆转录
  • 知道 DNA、RNA、蛋白数据各能支持什么结论
00 · THE MAP

Central Dogma 描述的是序列信息的传递

分子生物学的 Central Dogma / 中心法则可先画成 DNA → RNA → protein：一个蛋白编码基因的 DNA 被转录成 RNA，成熟 mRNA 在核糖体上被翻译成氨基酸链。箭头表示信息如何被读取，不表示每个基因都被表达，也不表示 RNA 多一倍时蛋白就多一倍。[NHGRI Central Dogma]

另有 DNA replication / DNA 复制：细胞分裂前复制整个基因组，属于 DNA → DNA。它与一个基因正在被转录不是同一件事。复制、转录、翻译分别回答“遗传材料怎样传下去”“哪段信息被抄出”“RNA 怎样指定氨基酸”。[NHGRI DNA Replication]

01 · TRANSCRIPTION

DNA 怎样“抄写”出 RNA？

双链 DNA 有两条方向相反的链。Template strand / 模板链被 RNA polymerase / RNA 聚合酶读取；RNA 聚合酶沿模板链 3′→5′ 方向读取，并按 5′→3′ 方向合成互补的 RNA；RNA 用 U（uracil）代替 DNA 的 T。Coding strand / 编码链在对应的转录区域与初始 RNA 的 5′→3′ 序列相同，只需把 T 改成 U。这里讨论的核基因通常在细胞核内转录。[NHGRI Transcription] [NHGRI RNA Fact Sheet]

跟着这个虚构且无内含子的极短编码片段逐行读。上、下两条 DNA 方向相反，RNA 与模板链互补：

DNA coding / 编码链5′–ATG GCT TAA–3′
DNA template / 模板链3′–TAC CGA ATT–5′
mRNA / 信使 RNA5′–AUG GCU UAA–3′

这只是练习方向与互补关系的例子；真实基因通常更长，且一个转录本还可能经过后续加工。

02 · RNA PROCESSING

初始 RNA 并非总能直接拿去翻译

对许多人类蛋白编码基因，初始 pre-mRNA / 前体 mRNA会经历 5′ cap / 5′ 端加帽、3′ poly(A) tail / 多聚腺苷酸尾及 splicing / 剪接。剪接通常去掉 introns / 内含子并连接 exons / 外显子，形成成熟 mRNA；加帽、加尾也参与 RNA 的稳定性、输出和翻译。具体加工方式会因转录本而异。[NCBI RNA Processing]

Alternative splicing / 可变剪接使同一基因的外显子以不同组合连接，可产生不同 transcript / 转录本。所以上面的无内含子例子只能演示序列读取，不能替代真实基因的转录本注释。一个 gene-level RNA 数值相同，也可能掩盖转录本比例变化。[NHGRI Alternative Splicing]

03 · TRANSLATION

核糖体每三个 RNA 碱基读作一个 codon

成熟 mRNA 到达细胞质后，ribosome / 核糖体按 5′→3′ 方向读取。Codon / 密码子是三个碱基一组；tRNA / 转运 RNA用互补的 anticodon 帮助把相应氨基酸带到核糖体。起始位置决定 reading frame / 阅读框，改变分组方式会改变后面读出的信息。[NHGRI Translation]

mRNA codonAUGGCUUAA
读出的意义Met / 甲硫氨酸
常见起始密码子Ala / 丙氨酸
加入氨基酸链Stop / 终止
不是氨基酸

在标准遗传密码表里，这段示意 mRNA 读作 Met–Ala–Stop：氨基酸链是 Met–Ala，遇到 UAA 停止。密码子有冗余性，几种不同 codon 也可能指定同一种氨基酸；实际起始与翻译效率还受周围序列和细胞状态影响。[NCBI Standard Genetic Code] [NHGRI Stop Codon]

04 · VARIANTS MEET THE CODE

为什么同是 DNA 变化，后果可以完全不同？

当变异落在蛋白编码区，可以根据转录本和阅读框描述其预测的分子后果。这仍不是细胞功能或疾病因果的最终证据：

术语对蛋白序列的典型影响解释边界
Synonymous / 同义codon 改变，氨基酸不变不等于已证实无功能影响
Missense / 错义一个氨基酸被另一个取代不保证蛋白功能改变
Nonsense / 无义出现提前终止密码子还需考虑转录本与位置
Frameshift / 移码插入或删除非 3 的倍数个碱基，后续分组改变影响取决于位置与转录本

定义依据 NHGRI Codon、Missense、Nonsense、Frameshift。

在调控区域或剪接位点的变异还可能改变 RNA 的数量或结构。第 7 课继续学习为何一个基因在不同细胞中会被不同方式使用。

05 · WHAT THE ARROW DOES NOT PROMISE

并非所有 RNA 都翻译，蛋白也不是表型的直接同义词

一些基因产生发挥功能的 non-coding RNA / 非编码 RNA，不以蛋白为终点。某些病毒及细胞内遗传元件还会通过 reverse transcription / 逆转录把 RNA 信息写回 DNA；因此 DNA → RNA → protein是常见入门路线，而非所有分子的完整流程图。逆转录也不意味着可以从蛋白质序列任意还原出原始核酸序列。[NHGRI RNA Fact Sheet]

新生氨基酸链还需折叠、定位，且蛋白丰度和活性可受修饰、降解及其他细胞条件影响。Protein / 蛋白质参与细胞结构与功能，但单个蛋白测量值不能直接等同于病人的表型。[NHGRI Protein]

06 · LINK TO DATA

对应到组学：三层读数回答三个不同问题

数据层典型问题不能直接推出
DNA sequencing这里的序列、变异、拷贝数是什么？这个基因正在表达
RNA-seq此样本有哪些 RNA、丰度如何？适当分析下剪接怎样？蛋白量或活性一定相同方向变化
Proteomics检测到了哪些蛋白或肽段信号？该蛋白单独导致某个临床结局

以 TCGA/GDC 的 mRNA 管线为例，reads 经比对和定量形成 gene counts 等结果。RNA-seq 不是把显微镜对准基因看它“开没开”；数值依赖样本、技术和处理流程。跨层推断需匹配同一病例和样本，并考虑细胞组成、批次与缺失。[GDC mRNA Pipeline] [EMBL-EBI PRIDE]

给 CS 读者的翻译

可以把 DNA、RNA、蛋白看作不同处理层的观测，但它们不是一条确定性流水线。一个 DNA diff、一次 RNA count 和一个蛋白信号来自不同实验；只有定义清楚样本、版本和因果假设，才能安全地把它们连接起来。

练习 1：编码链 5′–ATG GCT TAA–3′ 对应的 mRNA 和蛋白是什么？

若这是一段无内含子的编码片段，mRNA 为 5′–AUG GCU UAA–3′。标准遗传密码下，AUG 指 Met、GCU 指 Ala、UAA 指终止，得到 Met–Ala 的氨基酸链。

练习 2：某基因 RNA-seq 的 gene count 没变，能排除分子变化吗？

不能。不同转录本的比例可能变化；蛋白翻译、修饰和降解也可能变化。要按具体假设选择 transcript-level RNA、蛋白或其他实验。

练习 3：逆转录是否推翻了“蛋白不能还原 DNA 序列”的限制？

没有。逆转录是 RNA → DNA 的序列信息转移；它不提供蛋白质氨基酸序列 → 原核酸序列的逆向读取。

LESSON 07 / 12MOLECULAR BIOLOGY · REGULATION

基因怎样被调控？

同一份 DNA，可以在不同细胞里读出不同程序。

  • 认识 promoter、enhancer、transcription factor
  • 理解 chromatin 与 DNA methylation
  • 把调控概念对应到 ATAC-seq 数据
01 · WHICH GENE IS ON?

有基因，并不等于此刻在表达

Promoter / 启动子通常靠近转录起始位置；enhancer / 增强子可从较远位置影响表达；transcription factors / 转录因子是可结合 DNA 并参与调节转录的蛋白。它们参与决定何时、何地、以何种水平表达某个基因。调控关系依赖细胞类型和状态，不能仅用“附近有 enhancer”推定靶基因。[ENCODE]

enhancer远端调控区域↝promoter起始附近→gene→RNA
02 · ACCESS CONTROL

染色质把“可被读取”变成一个变量

DNA 与蛋白共同组织成 chromatin / 染色质。较开放的区域通常更容易被调控蛋白接近；ATAC-seq 测量染色质可及性。Epigenome / 表观基因组包含与基因使用有关的化学标记与结构状态；DNA methylation / 甲基化是常见测量。[ENCODE ATAC-seq]

开放染色质峰、甲基化数值和 RNA 表达是三种观测。一个峰存在不代表该基因一定上调；甲基化与表达的关系取决于位置和背景。多层证据要放在相应的细胞类型、样本和参考坐标中讨论。

03 · DATA SHAPE

调控组学常是“区域 × 样本”

RNA 表常是 gene × sample；ATAC 常用 peak × sample，甲基化可用 CpG site / region × sample。Peak / 峰是统计识别的高信号区域，不自动等于一个功能元件。把 peak 连接到 gene 是额外推断，需说明距离规则或实验依据。[ENCODE Data Standards]

给 CS 读者的翻译

可以把调控想成带上下文的访问控制，但 DNA 不是静态配置文件。细胞类型、信号与环境会改变这些条件。

检查理解：为什么 ATAC peak 附近有基因 X，不能直接说 peak 调控 X？

空间接近只是候选线索；增强子可能作用于更远的基因，peak 也不等于已证实功能。还需表达、染色质接触或扰动实验等证据。

本课来源 ENCODE · ATAC-seq · NHGRI Epigenome

LESSON 08 / 12CELL BIOLOGY · CANCER

细胞、组织与癌症

一份肿瘤样本不是一种细胞，也不是均匀的系统。

  • 认识细胞器、cell cycle 和信号通路
  • 从 cell 到 tissue 到 patient 识别尺度
  • 解释 tumor microenvironment 与 heterogeneity
  • 理解 bulk 信号为何受细胞组成影响
01 · THE UNIT OF LIFE

组织由多类细胞组成

细胞由膜包围，具有内部结构，并与周围环境交换物质和信号。一个组织样本可能包含上皮细胞、免疫细胞、成纤维细胞和血管相关细胞。细胞类型代表相对稳定的身份，cell state / 细胞状态则可随刺激、分化或疾病变化。[NHGRI Cell]

02 · CELL COMPARTMENTS

先定位分子在细胞里的“工作地点”

人体细胞不是一个没有内部结构的袋子。Cell membrane / 细胞膜隔开内外并参与物质和信号交换；nucleus / 细胞核容纳大部分染色体 DNA；ribosome / 核糖体读取 mRNA 合成蛋白；mitochondria / 线粒体参与能量代谢，并有自己的少量 DNA。这样回看上一课：核基因的转录通常发生在细胞核，而 mRNA 的翻译发生在细胞质中的核糖体。[NHGRI Organelle] [NHGRI Mitochondria]

MEMBRANE边界与信号

决定什么进入、离开或被感知

NUCLEUS染色体与转录

主要核基因组所在处

RIBOSOME翻译 mRNA

把 codon 读成氨基酸链

原创功能定位卡片；依据 NHGRI Cell Membrane、Nucleus、Ribosome。

03 · CELL CYCLE

细胞怎样复制自己？

Cell cycle / 细胞周期可简记为 G1 → S → G2 → M：准备生长，S 期复制 DNA，G2 期为分裂做准备，M 期通过 mitosis / 有丝分裂把复制后的染色体分给两个子细胞。第 4 课的 meiosis / 减数分裂用于形成生殖细胞，目的和染色体结局不同。[NHGRI Cell Cycle]

G1生长准备→S复制 DNA→G2检查与准备→M有丝分裂

癌症并不是“细胞分裂快”这一个数字，而是控制生长、分裂和存活的多种机制出现异常。DNA 变化可影响调控这些过程的基因；随后不同细胞群体在肿瘤中扩张。[NCI What Is Cancer?]

04 · CELL SIGNALING

细胞如何把外界信息变成内部反应？

细胞并非只执行 DNA 中的一份固定程序。生长因子等外界 ligand / 配体可以结合细胞表面或内部的 receptor / 受体，信号再经细胞内分子传递，促成分裂、死亡、移动或基因表达变化。这一过程叫 signal transduction / 信号转导。不同细胞拥有不同受体和内部状态，所以接到相似信号，也未必产生相同反应。[NCI Signal Transduction]

OUTSIDELigand生长因子等→MEMBRANEReceptor感知信号→INSIDERelay分子间传递→RESPONSECell state表达或行为改变

原创教学示意，箭头表示可能的信息传递路径，不代表每条通路都按此单线运行。依据 NCI Signal Transduction 和 NHGRI Biological Pathways。

Pathway / 生物通路是研究者把一系列相关分子作用组织起来的模型，可涉及信号、代谢或基因调控；真实细胞里通路互相连接，不是四个方框组成的独立直线。Reactome 提供经整理的反应和通路作为参考。若在 TCGA RNA-seq 中发现一组通路基因的表达升高，这提示相关生物过程值得追查，却不能仅凭 RNA 数值断定受体已被激活或通路具有因果作用；还要结合蛋白活性、细胞组成与实验验证。[NHGRI Biological Pathways] [Reactome Data Model]

05 · WHY CANCER IS DIFFERENT

癌症是细胞调控失常，也是在演化的群体

癌症细胞获得促使其异常生长与扩散的改变。同一患者的肿瘤细胞可能不完全相同，且会与免疫细胞、基质细胞等构成的 tumor microenvironment / 肿瘤微环境相互影响。不同部位、时间和治疗状态取样，可能得到不同分子图景。[NCI]

06 · MIXING SIGNALS

Bulk 测量是混合后的结果

若一块组织的 RNA 混在一起测量，某基因的高表达可能是肿瘤细胞表达升高，也可能只是表达该基因的免疫细胞比例变高。Tumor purity / 肿瘤纯度描述样本中肿瘤细胞所占程度；它会影响变异检测、CNV 和表达的解释。分析时记录取样位置、病理类型与纯度估计，并在可能时用单细胞或空间数据核对来源。[GDC About Data]

给 CS 读者的翻译

一个 bulk sample 像把多个服务的日志合并后只给总计数。总量变化可能来自服务内部行为，也可能来自各服务流量占比变化。

检查理解：bulk RNA 中免疫标记上升，有哪两种主要解释？

免疫细胞数量或比例增加；或相同数量的免疫细胞中每个细胞表达更多。仅凭 bulk 均值一般不能分开这两种情况。

检查理解：TCGA RNA-seq 中一组通路基因表达升高，能说通路已被激活吗？

不能直接这样说。RNA 是转录层读数，受细胞组成和技术因素影响；受体或下游蛋白的活性还需相应蛋白、修饰或功能实验等证据来判断。

本课来源 NCI What Is Cancer? · GDC About Data · NHGRI Cell · Cell Cycle · Organelle · NCI Signal Transduction · NHGRI Biological Pathways · Reactome

LESSON 09 / 12MEASUREMENT · EXPERIMENT

一次实验如何变成数据？

从患者和组织，到文件和矩阵；每一步都可能改变结论。

  • 区分 case、sample、aliquot、file
  • 认识 FASTQ → alignment → count
  • 识别生物重复、技术重复、批次与泄漏
01 · FOLLOW THE SPECIMEN

同一个人可以贡献多个样本和文件

在 GDC/TCGA 语境中，case 通常对应一个研究参与者；sample 指取出的生物材料，如原发肿瘤或正常组织；材料可进一步分装成 aliquot；不同实验和处理步骤可产生多个 file。这些 ID 不是同义词。[GDC Barcode]

Casepatient→Sampletumor / normal→Aliquotmaterial→Fileassay output

如果一个患者有两份肿瘤样本，而每份又有多个文件，将文件行数当作患者数会造成 pseudoreplication / 伪重复。训练集与测试集也要按患者或更高的独立单位拆分，避免同一患者的信号同时出现在两边。

02 · MEASUREMENT CHAIN

测序数据经过处理才成为表格

以 RNA-seq 为例：取样 → 提取 RNA → 建库 → 测序得到 reads / 读段。原始读段及质量信息通常放在 FASTQ；随后进行比对或定量，最后形成 gene/transcript count 表。管线和注释版本不同，数值也可能改变，因此 count 是处理结果，不是直接从组织中读出的绝对分子数。[GDC mRNA Pipeline] [GA4GH Formats]

03 · DESIGN BEFORE MODEL

重复、批次与 metadata 决定你能比较什么

Biological replicate / 生物重复来自研究问题所定义的独立生物单位；若目标是患者层面的推断，同一患者两块组织仍属于同一患者。Technical replicate / 技术重复是对同一材料重复测量，主要帮助评估测量波动。Batch / 批次可能来自取样中心、建库日期、测序平台或处理版本。Metadata / 元数据记录这些上下文，以及组织、时间点、治疗和临床字段。若病例组与对照组分别在两个批次处理，算法很难区分疾病与批次。[NCBI GEO Experimental Metadata]

给 CS 读者的翻译

把表格的每一行映射回真实世界中的独立对象。一个文件、一个 aliquot、一块组织与一个患者代表不同的样本量。

检查理解：100 个 RNA 文件来自 50 位患者，可直接报告 n=100 吗？

如果推断目标是患者层面，不能。先查文件与 sample、case 的映射，以及每个患者为何有多个文件；有效独立样本量应按患者层面定义。

本课来源 GDC TCGA Barcode · GDC mRNA Pipeline · NCBI GEO MIAME

LESSON 10 / 12MEASUREMENT · OMICS

Omics 究竟在测什么？

记住观测对象、矩阵形状和盲点，才能正确连接多组学。

  • 区分 WGS/WES、RNA-seq、ATAC、甲基化、蛋白质组
  • 为每层数据说出行、列与单位
  • 解释多组学关联为什么尚非因果机制
01 · MEASURED LAYERS

Omics 是大范围测量，不是一种文件

Genomics / 基因组学关注 DNA；transcriptomics / 转录组学关注 RNA；epigenomics / 表观组学关注调控相关状态；proteomics / 蛋白质组学关注蛋白或肽段。每一层是系统的一种投影，不能互相代替。[GDC]

Assay / 测量直接观测常见数据形状不能直接回答
WGS / WES全基因组 / 外显子富集后的 DNA readsvariant × sample；segment × sample变异是否被表达或有功能
RNA-seqRNA 读段与定量gene / transcript × sample蛋白活性；细胞来源
ATAC-seq染色质可及性peak × sample峰调控哪一个 gene
DNA methylation位点或区域甲基化CpG / region × sample表达方向的普遍规律
Mass spectrometry肽段和蛋白相关信号peptide / protein × sample所有蛋白的完整覆盖

教学抽象；实际文件可能是 reads、peak 区间、分段结果或量化矩阵。依据 GDC、ENCODE、PRIDE。

02 · CONNECT THE LAYERS

先对齐样本，再谈跨层关系

假设你想问“某基因拷贝数增加是否伴随 RNA 增加”。需要同一病例中可匹配的 DNA 与 RNA 样本，明确 tumor/normal、参考版本、gene ID、处理方式，以及每层有多少缺失。CNV → RNA 是机制假设；横截面关联只提供部分证据。[GDC Data Documentation]

常见陷阱：只保留所有组学都有数据的病例会改变队列构成；混合癌种可能得到组织来源驱动的模式；在数万个特征上反复尝试，需要考虑多重检验和独立验证。

给 CS 读者的翻译

多组学是多个不完整、噪声结构不同的 view。连接之前，先写清 join key、观测单位和缺失机制。

检查理解：RNA 与 CNV 表格都有“TP53”一行，就能直接相关分析吗？

不能。还要确认行的定义与版本、列是否匹配同一患者及样本类型、是否有缺失，并决定分析对应的生物问题。

本课来源 NCI GDC About Data · ENCODE ATAC-seq · EMBL-EBI PRIDE

LESSON 11 / 12MEASUREMENT · RESOLUTION

单细胞、空间与影像

换一个观测尺度，问题和误差结构也会改变。

  • 认识 microscopy、WSI、CT/MRI 的分析单位
  • 识别患者级数据泄漏
01 · MOLECULAR RESOLUTION

从组织平均到细胞，再到空间位置

Bulk RNA-seq 得到一份组织的混合表达；single-cell RNA-seq, scRNA-seq 把表达记录关联到单个细胞或细胞核，可研究细胞类型和状态；spatial transcriptomics / 空间转录组保留测量在组织中的位置。空间测量的一个 spot 不总等于一个细胞，具体分辨率取决于技术。[CELLxGENE] [NCBI GEO]

图像也有不同生物尺度

显微镜图像可看细胞与亚细胞结构；whole-slide image, WSI / 数字病理全切片可看组织形态；CT/MRI 医学影像可看器官与病灶的三维解剖。它们可能用像素、tile、slide、scan 或 patient 作为单位。[Image Data Resource] [TCIA]

03 · VALIDATION UNIT

切片和 tile 不是独立患者

同一患者的多个细胞、spot、tile 或扫描高度相关。若任务是预测患者级结局，应按患者拆分训练与测试，并在评估时回到患者级汇总。把同一张切片的 tile 随机分到训练与测试，会让模型看到极相似的材料，得出过于乐观的结果。单细胞研究也要区分“细胞数很多”和“独立供体数很多”。

给 CS 读者的翻译

把嵌套关系画出来：像素 ⊂ tile ⊂ slide ⊂ patient，细胞 ⊂ sample ⊂ patient。交叉验证的分组键应对应你想推广到的独立单位。

检查理解：10 万个细胞来自 3 位患者，患者层面的 n 是多少？

是 3 位独立患者。细胞很多有助于描述这些患者中的细胞状态，但不能替代更多独立患者来估计人群层面的不确定性。

LESSON 12 / 12RESEARCH PRACTICE · TCGA

第一次做 TCGA 研究

从具体问题出发，建立可追溯的病例队列和证据链。

  • 区分 TCGA、GDC、GEO、SRA 等资源角色
  • 写出病例、样本、数据层和结局的纳入规则
  • 识别关联分析的解释边界
01 · PICK THE RIGHT RESOURCE

数据集名称代表不同角色

TCGA 是癌症基因组研究项目；NCI GDC 提供癌症数据的检索、下载及协调处理数据。GEO 是功能基因组学研究提交仓库，通常按 study（GSE）与 sample（GSM）组织；SRA 更偏向原始测序读段。正常组织表达参考可看 GTEx；调控实验看 ENCODE；单细胞看 CELLxGENE；蛋白质组看 PRIDE；影像看 TCIA。这些资源的样本来源、处理方式和使用条款不同。查看完整数据集地图 ↗

02 · A CONCRETE QUESTION

先写问题，再打开下载页面

练习问题：在 TCGA 的某一指定癌种中，某基因的 RNA 表达与临床结局是否相关？把癌种、基因、结局和比较方式在分析前写明。记录癌种项目、primary tumor 或 normal、病理/治疗等纳排条件，以及结局字段和随访时间的定义。所得是关联，不能直接证明该基因导致预后改变。[GDC]

  1. Define cohort在 GDC 选项目、样本类型与病例；保存检索条件及日期。
  2. Audit IDs分别统计 case、sample、aliquot、file，检查重复材料。
  3. Choose data选 RNA quantification 和临床字段；记录工作流与版本。
  4. Join carefully按 case/sample 层级对齐；列出有数据与缺失的病例数。
  5. Challenge result检查混杂、纯度、批次、极端值、多重检验与独立验证。

GDC 的协调处理帮助跨项目比较，但不会自动解决实验设计、样本选择或临床字段缺失。[GDC Data]

03 · MULTI-OMICS EXTENSION

再加入 DNA、调控或影像

若问“拷贝数是否伴随表达改变”，在原队列中加入 CNV，计算 RNA 与 CNV 的病例交集，并记录失去多少病例。若加突变，确定 somatic calls 的检测范围、过滤规则及样本对应关系。若加 WSI 或 CT，确认图像与分子数据确属同一病例，且病例级划分贯穿分析。每加一层，都重新核对独立单位、缺失和批次。

写在 README 里的最小研究记录question · cohort rule · case/sample IDs · assay & workflow · genome build · exclusions · missingness · analysis unit · validation plan

发布结果时，注明数据来源、访问日期、项目和处理版本；受控数据需按资源规定申请访问。[GDC Documentation]

给 CS 读者的翻译

研究项目像一条有版本的数据管线：定义实体和 join key、固定输入版本、记录过滤、预先定好评估单位。漂亮的模型无法补救错误的 cohort。

检查理解：为什么多组学交集减少时，要重新描述 cohort？

剩下的病例可能与原队列在亚型、分期、医院或样本质量上不同；分析对象已改变，原队列结论不能直接照搬。
