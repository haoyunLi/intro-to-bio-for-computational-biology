01 / INFORMATION FLOW

DNA 信息怎样指导蛋白质合成？

先把 DNA 想成一串由 A、C、G、T 写成的序列。转录 transcription 生成 RNA；翻译 translation 按三个 RNA 字母为一组读取，连接氨基酸。下面只模拟一个已确定阅读框、没有内含子的短编码区。

改变输入序列

5′ → 3′ coding strand

只能输入 A/C/G/T；长度 3–36 且为 3 的倍数。示例从 ATG 开始，以 TAA 结束。

播放会按碱基和密码子推进；也可用下一步直接查看一个阶段。速度为教学设定，不代表分子反应速度。

5′ ATG GCT GAA TAA 3′
DNA · template / 模板链互补、反向平行
mRNA · 转录本示意：T 被 U 替代
蛋白质 · 氨基酸序列在首密码子 AUG 启动，遇终止密码子停止

这与真实数据怎样连接？

DNA sequence / VCF

一行通常记录一处相对参考序列的变异；不直接给出 RNA 或蛋白丰度。

RNA-seq count

矩阵一个值是某样本中归给某基因的 reads/fragments 数；不是这个基因的 DNA 拷贝数。

0 代表什么？

这里的“零”要看测量层：RNA count=0 是没有 read 被分配；不能证明 DNA 缺失或蛋白绝不存在。

模型边界：真实基因有启动子、外显子/内含子、剪接、UTR、不同转录本和调控。本页的序列输出只演示密码表，不能推出细胞中实际表达量。

一个 0

在这个理想模型中，0 表示样本里没有产生该 marker 的那一类细胞（另一类细胞的该 marker 设为 0）。真实 count=0 也可能是检测不足，不能直接说该基因不存在。

合法推断：样本 B 的免疫 marker 可以仅因免疫细胞较多而升高；无需假设单个免疫细胞改变了表达。单靠 bulk 的这一行，无法唯一拆出细胞比例与每细胞表达。

03 / MEASUREMENT SCALE

同一份 RNA，为什么会有三种数字？

测序仪先得到 reads；定量流程按文库与计数规则将 reads 或 fragments 分配给基因，形成 raw count。再改变“分母”或考虑长度，就能得到不同问题的尺度。切换下面的场景与单位，重点观察基因 G1。

柱长按当前两根柱的最大值缩放，只比较同一尺度下的 A 与 B；切换单位后不跨尺度比较柱长。文字数字始终是目标值。

先问一个数的单位

Raw count

这个样本中分配到该基因的 read/fragment 计数，取决于文库与流程。不同计数总量下，直接比较可能误导。

CPM

本题 gene count ÷ 三行 gene counts 合计 × 10⁶。它按纳入计数总量缩放，是相对份额；真实分母须看 workflow。

TPM

本题先用假设长度（kb）校正 count，再把三行的长度校正值缩放，使未四舍五入的总和为 10⁶。适合描述同一样本里的相对丰度；并非“每细胞 RNA 分子数”。

0 代表什么？

raw=0 表示该基因没有 read/fragment 被分配；在本题分母有效时 CPM/TPM 也是 0。低表达、低测序深度与技术检测问题都可能造成零。

模型边界：只有三基因、没有生物重复；CPM/TPM 不是差异表达的显著性检验。真实 TPM 依赖定量层级、纳入的 feature 集合与长度定义（gene length 或 transcript effective length）；差异分析通常从原始计数和适当统计模型出发。

依据：Wagner et al. TPM 原始论文 ↗ · GDC mRNA Pipeline ↗ · DESeq2 Vignette ↗

读任何组学矩阵，先问四句。

  1. 一行是 gene、transcript、cell，还是 sample？
  2. 一个值来自什么实验步骤，单位是什么？
  3. 一个零是生物学缺失，还是未被测到？
  4. 这个比较还可能由细胞组成、深度或批次解释吗？
