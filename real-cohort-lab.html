    先认清层级

    四行元数据，数出几个对象？

    一个 case 是 GDC 数据模型中的病例/受试对象；同一 case 可以贡献多个 sample（组织样本），一个 sample 又可以关联一个或多个 file（数据文件）。所以文件数不能直接当人数。GDC Case 定义 ↗

    GDC 文件元数据 · 每行是一份 file点击 file ID 查看官方记录

    窄屏时左右滑动表格，可查看 sample_type 和 file_id。

    case.submitter_idsample.submitter_idsample_typefile_id

    你的判断

    分别数不重复的 case、sample、file。一个 case 重复出现在两行时只算一次。

    把它想成数据库的三张表。 case ID 是病例键，sample ID 是一次组织采样的键，file UUID 是一份输出文件的键。这里每个病例正好有两种 sample；这是我们挑出的练习子集，不代表整个 TCGA-BRCA 的结构。GDC Data Model ↗
    02 / 06

    筛选 sample_type

    哪些是肿瘤样本？

    sample_type 是元数据字段。这里有 Primary Tumor 和 Solid Tissue Normal 两类。TCGA barcode 中的 01 与 11 也编码样本类型，但实际筛选先看显式字段，并保留原标签。TCGA Barcode ↗

    请选择所有 Primary Tumor 样本。按 sample 选择，不要按 case 选择。

    同一病例也可能有不同组织类型。 这里每个 case 各有一份 Primary Tumor 和一份 Solid Tissue Normal。后者是 GDC 的样本分类名称，不表示“完全健康”，也不是独立人群的对照组。文件之间仍需用 case ID 配对。

    读懂一个数

    基因的 0 和高值说明什么？

    GDC 的 STAR 流程把测序片段比对到参考基因组，再给基因计数。unstranded 是本文件中的原始基因读数；tpm_unstranded 是由读数计算出的标准化量。下面只展示完整 TSV 中的四条真实基因行；原文件还包含更多基因与 QC 行。GDC mRNA 流程 ↗

    casesample_typegene_idgene_nameunstranded
    raw count    		tpm_unstranded
    TPM

    字段名与小数位保留自 GDC TSV；上表不是整份表达矩阵。切换基因可见不同观察值。

    如果 INS 在某份文件里 unstranded = 0，可以怎么读？

    0 是测量结果，不是“生物学上绝对不存在”。 读深、组织中细胞比例、转录本水平、比对和注释都会影响观测。一个很高的数也只是该样本在该流程下的较高读数；不能单凭这四行解释原因。
    05 / 06

    raw counts 与 TPM

    同一个基因，为何有两列数？

    举例看 ESR1：同一行同时有原始 unstranded 与 tpm_unstranded。TPM 结合基因长度与样本总量做相对尺度转换；两列单位不同，不能把它们当作重复测量。GDC TPM 计算说明 ↗

    把字段放到合适的任务

    数据用途取决于问题。 raw counts 保留计数特性，是计数模型常用输入；TPM 可作描述性展示和探索。TPM 不是基因拷贝数，也不是 0–100 的百分比；跨样本 TPM 差别仍会受组成及采样影响，不能自行当作显著性检验。

    推断边界

    现在你能说什么？

    我们是有意选出两组有配对样本的病例，仅保留四个基因行，没有完整样本质控、临床结局、混杂因素或足够的独立重复。下面选出仅凭本页数据能够核验的陈述。

    能描述观察值，不能替代研究设计。 此页不能宣称“某基因在乳腺癌中显著上调”、推断肿瘤导致了变化、估计总体效应，或预测治疗效果。若要做差异表达，需要明确生物学重复、比较组、质控、潜在混杂因素与统计模型；若要做临床问题，还要取得相应临床资料并定义结局。

    SOURCE & REPRODUCIBILITY

    每个数字从哪里来

    数据来自 NCI Genomic Data Commons (GDC)。本站 JSON 快照 ↓ 同时保存：完整 TCGA-BRCA 公开 STAR Counts 清单的聚合计数、两位病例的公开临床字段，以及四份经原文件 MD5 核验的配对表达摘录。页面只读该快照，离线静态托管不请求 GDC API。

    如何复现与核对
    1. 向 GDC /files 端点提交快照中的 project、data_type、workflow 与 access 过滤条件；分别对 file、sample、case 去重，并按 sample_type 汇总。
    2. 通过 case_id 到 /cases 端点取得 clinical/demographic/diagnosis 字段；不要用 sample_id 或 file_id 直接连接病例级临床表。
    3. 点击下方每份 file_id，核对 cases、samples、analysis、md5sum；再从 /data/{file_id} 下载完整 TSV 并核对 MD5。
    4. 按原 TSV 的 gene_name 精确选出 TSPAN6、ESR1、ERBB2、INS 四行。本站未修改表达值；这些行只支持教学计算，不等于完整表达矩阵。

    背景与字段解释：GDC API、文件下载、mRNA 定量与 TPM、TCGA barcode。本站仅重现一小部分公开数据，并注明来源；GDC 数据使用请遵守其 数据政策。
